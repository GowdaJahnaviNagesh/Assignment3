# Assignment 2 – Authentication Pages (HTML Only)

This project contains basic authentication pages created using only HTML, as per the assignment requirements.

## Pages Included

1. Login Page
   - Username and Password fields
   - Login button (redirects to Dashboard)
   - Forgot Password link
   - Create New Account link

2. Register Page
   - Name, Email ID, Phone Number
   - Password and Confirm Password
   - Register button (redirects to Login page)
   - "I already have an account" link

3. Forgot Password Page
   - Email input field
   - Send password reset link button (redirects to Login page)

4. Reset Password Page
   - New Password and Confirm Password fields
   - Update Password button (redirects to Login page)

5. Dashboard Page
   - Welcome message
   - Logout button (redirects to Login page)

## Project Structure
assignment-auth-pages/
│── login.html
│── register.html
│── forgot-password.html
│── reset-password.html
│── dashboard.html
│── README.md


## How to Run
1. Download or clone the repository
2. Open `login.html` in any web browser
3. Navigate between pages using buttons and links

## Technologies Used
- HTML5
- No CSS / No JavaScript (as per assignment requirement)
